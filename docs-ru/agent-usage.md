# Гайд для агента

Как ИИ-агенту вести resq-mcp, чтобы реально понять незнакомый QVM, а не
просто перечислить его.

## Настройка

Направьте MCP-клиент на бинарник:

```json
{ "mcpServers": { "resq": { "command": ".../resq-mcp.exe", "args": ["C:/mods/x/vm/qagame.qvm"] } } }
```

Предзагрузка через `args` экономит один круг инструмента; `open_qvm`
тоже работает и позволяет менять образ посреди сессии.

## Рекомендованный сценарий (неизвестный модуль)

1. **Осмотр.** `session_info` — тип модуля и размеры говорят, перед вами
   что (qagame/cgame/ui). `named_functions: 0`? Чистый образ — всё
   адресуется как `fn_<idx>`, пока не появится `.map`.

2. **Сначала строки.** `get_strings` — самая дешёвая поверхность
   ориентирования: имена cvar-ов (`"g_gametype"`), configstrings
   (`"cs_%i"`), ошибки полей сущностей (`"G_Spawn: %s doesn't have a
   spawn function"`), надписи UI. Ищите ключевые слова игрового потока:
   `filter: "InitGame"`, `"ClientConnect"`, `"score"`.

3. **Якорь через xrefs.** Взяли говорящую строку — `xrefs_to` её адреса.
   Ссылающиеся функции — ваши кандидаты (функция, цитирующая
   `"InitGame"`, и ЕСТЬ `G_InitGame`, или его вызывает).

4. **Декомпилируйте якорь, а не весь модуль.** `decompile_function`
   кандидата; читаете C. Callees из `get_function` расширяют фронт —
   танки с единственным трапом (`trap_SendServerCommand`) рассказывают
   всю историю бесплатно.

5. **Сисколл-обёртки дают бесплатный словарь.** `list_functions` с
   `filter: "trap_"` перечисляет всех пользователей трапов; маленькие
   функции с ровно одним трапом — движковые обёртки, фактически часть
   поверхности SDK.

6. **Модель памяти.** `mem_hint` по адресу, прежде чем рассуждать о нём:
   `[0x247d0] data = 5` — константа; адреса `BSS` — рантайм-глобалы, в
   образе они нулевые, реальное значение существует только в живой игре.

7. **Держите таблицу символов.** Ведите свою карту имя→idx в рабочих
   заметках и во всех вызовах адресуйте функции как `"fn_402"`. Когда
   найдётся настоящий `.map` — перезапустите с `open_qvm {path,
   map_path}`: все ответы станут именованными.

## Правила этикета для агентов

- **Пагинация.** Дефолты `list_functions`/`get_strings` — 200/200 строк —
  уже много токенов; не задирайте `limit` без нужды, предпочитайте
  фильтры.
- **Предпочитайте `decompile_function`, а не `disassemble_function`.**
  Читайте C; к листингу переходите, только когда C выглядит неправильно
  (странные переходы, таблицы switch).
- **Identity C — истина, а не идиоматичный C.** Типов нет; циклы
  восстанавливаются не дальше SSA — арифметика указателей вида
  `*(<int>*)((loc_20) + (704))` означает «поле со смещением 704 той
  структуры, что живёт в loc_20».
- **Одна сессия — один QVM.** `open_qvm` сбрасывает состояние; после
  смены образа повторите шаги осмотра.
- **isError — обратная связь по задаче** («нет QVM», «нет функции X») —
  правьте вызов, а не тупо повторяйте.

## Чем этот сервер НЕ является

- Не эмулятор игры: код не исполняется, рантайм-состояния нет (это
  `emu` из RESQ-kit, сюда пока не вынесен).
- Не слой персистентности: переименования/типы из sidecar-ов гуишки
  (`.map`, `types.json`) читаются через `open_qvm` `map_path`, но API
  записи пока нет.
